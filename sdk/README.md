# @covenant/sdk

**Audience:** developers building on Covenant: strategy operators committing
epochs, and tooling reading the chain. This is the reference for the
TypeScript SDK's public API, env surface, and tests. **Scope:** `sdk/` at
v0.1.0. The byte-level rules the SDK implements are normative in
[../docs/protocol.md](../docs/protocol.md).

The SDK is the protocol's reference implementation of the receipt encoding
and the sorted-pair Merkle scheme: the Rust contract and the Python agent
are both fixture-tested against it. Any change to `receipt.ts` or
`merkle.ts` is a protocol change ([../docs/protocol.md](../docs/protocol.md), section 4).

## What it provides

- Canonical trade receipts: build, validate, ABI-encode, hash.
- Sorted-pair Merkle trees with position-free proofs.
- `EpochBuilder`: per-epoch accumulation with protocol invariants enforced.
- `CovenantReader` / `CovenantOperator`: typed viem clients for reads and
  operator transactions against the Stylus contract.
- The Covenant ABI and USDG addresses.

Dependency: `viem` only.

## Public API surface

Everything below is exported from the package root (`sdk/src/index.ts`).

### Receipts (`sdk/src/receipt.ts`)

| Export | What it does |
| --- | --- |
| `Venue` | enum: `Coinbase = 0`, `ArbitrumDex = 1`, `Other = 2` |
| `Side` | enum: `Buy = 0`, `Sell = 1` |
| `makeReceipt(args)` | builds a `ReceiptInput` from human units; derives the size sign from `side`, hashes the raw venue order id and instrument strings |
| `validateReceipt(r)` | returns the list of invariant violations (side/size agreement, price > 0, field ranges); empty list = valid |
| `encodeReceipt(r)` | ABI-encodes the receipt exactly as the contract expects |
| `receiptHash(r)` | canonical leaf hash; throws on structurally invalid receipts |
| `parseFixed8(x)` | exact decimal string/number to 8-decimals fixed point bigint; throws on more than 8 fractional digits |

### Merkle (`sdk/src/merkle.ts`)

| Export | What it does |
| --- | --- |
| `buildMerkleTree(leaves)` | builds the sorted-pair tree; throws on an empty leaf list (an empty epoch must not commit a tree); single leaf: root == leaf, proof == [] |
| `verifyProof(leaf, proof, root)` | position-free proof verification |
| `MerkleTree` | interface: `leaves`, `root`, `proof(i)` |

### Epochs (`sdk/src/epoch.ts`)

`EpochBuilder(strategyId, epochIndex)` enforces, throwing on violation:

- a receipt's `strategyId`/`epochIndex` match the builder's;
- `venueOrderIdHash` is unique within the epoch;
- receipts arrive with non-decreasing `filledAt`;
- structural validity (`validateReceipt`).

Methods: `add(r)`, `size`, `tree()` (throws on zero receipts),
`commitPayload({ equityUsdg, netFlowUsdg, evidenceURI })` (refuses zero
receipts) producing the `CommitPayload` the operator client consumes. Also
exports `canonicalInstrumentHash(instrument)`.

### Clients (`sdk/src/client.ts`)

- `CovenantReader(address, publicClient)` or `CovenantReader.create(address, chain, rpcUrl)`:
  `config()`, `strategyCount()`, `getStrategy(id)`, `getPerformance(id)`,
  `getCheckpoint(strategyId, epochIndex)`, `verifyReceipt(...)`,
  `listStrategies()`.
- `CovenantOperator(address, walletClient, publicClient)`: wraps a viem
  wallet for `registerStrategy`, `commitEpoch` (takes an `EpochBuilder`
  `CommitPayload`), `finalizeEpoch`, `challengeEpoch`. Approve the USDG
  bond to the contract before `registerStrategy`.
- `CheckpointStatus` (0 Pending, 1 Finalized, 2 Challenged, 3 Invalidated)
  and `StrategyStatus` (0 Active, 1 Suspended) mirror the contract.
- `formatUsdg(baseUnits)` renders 6-decimal USDG base units for display.

### ABI and constants (`sdk/src/abi.ts`)

`covenantAbi` (hand-maintained mirror of the exported
`contracts/covenant/abi/ICovenant.sol`; keep in sync) and `USDG`
(Arbitrum One and Arbitrum Sepolia addresses; 6 decimals on all chains).

## Env vars

None. The SDK is a library: RPC URLs, chains, and wallets come in through
the constructor arguments. Chain choices are viem `Chain` objects, e.g.
`arbitrumSepolia` from `viem/chains`.

## Tests

```bash
pnpm install                     # repo root, once
pnpm --filter @covenant/sdk test # builds, then node:test: 8/8 green
pnpm --filter @covenant/sdk run typecheck
```

The suite (`sdk/test/sdk.test.ts`) covers exact fixed-point parsing, sign
enforcement, hash-of-string behavior, tree/proof behavior across sizes plus
a randomized property test, and the `EpochBuilder` invariants. The shared
cross-language fixtures are generated by `sdk/scripts/gen-fixtures.ts`
(writes `contracts/merkle-core/tests/fixtures/merkle.json`); regenerate them
only as part of a protocol change ([../docs/protocol.md](../docs/protocol.md), section 4).

## How it connects to the others

- The Rust contract consumes roots and verifies proofs with the same
  semantics (`contracts/merkle-core/`), fixture-tested against files this
  SDK generates.
- The Python agent mirrors `receipt.ts`/`merkle.ts` byte-for-byte
  (`vouch/vouch/attest/`), fixture-tested against SDK-generated vectors.
- The indexer imports `covenantAbi` from this package to decode logs
  (`indexer/src/transport.ts`).
- The web app imports the SDK for the ABI used in browser-side receipt
  verification, and the agent's Node bridge imports the built
  `sdk/dist/src/abi.js` (`vouch/attest/bridge.mjs`).
